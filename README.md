# ABSÜRT FELSEFE ÜRETİCİSİ

## Resmi ve Ciddi Tanıtım

Bu proje, insanlığın varoluşsal krizlerine **kesin çözüm** getirmek üzere tasarlanmış, son derece bilimsel ve abartısız bir yazılımdır.

Evet, okuduğunuz gibi: **Kesin çözüm.**

### Ne İşe Yarar?

- Rastgele kelimeleri birleştirerek size **derin** felsefi sözler sunar.
- Hayatınızı değiştirmez (resmi açıklama).
- Düşünmenizi sağlar (belki).
- Çay içerken okunması tavsiye edilir.
- Hiçbir akademik değeri yoktur. Bu bir özelliktir, hata değil.

### Nasıl Çalıştırılır?

```bash
python3 uretici.py
```

Program yavaş yavaş (sanki derin düşünüyormuş gibi) size bir söz sunacaktır.  
Örnek çıktı:

```
Varlık dans eder bir kedinin bakışında. Belki de hiçbiri önemli değildir.
```

Evet, bu kadar. Daha fazlasını beklemeyin.
